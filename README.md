## 보는 방법

- 넘기기: `→` `←` 키, 스페이스, 마우스 휠, 화면 아래 화살표 단추. 휴대폰에서는 옆으로 밀기
- 처음 · 끝으로: `Home` · `End`
- 전체 화면: `F`
- 인쇄 · PDF 저장: `P` (A4 가로, 26쪽)
- 특정 장표로 바로 가기: 주소 끝에 `#번호` (예: `…/kmtech-intro/#8`)

## 파일

- `index.html`, `css/`, `js/`, `assets/` — 소개서 본체
- `광명테크솔루션_회사소개서.html` — 파일 하나로 합친 버전. 내려받아 두면 어디서 열어도 깨지지 않습니다 (글꼴만 인터넷에서 받습니다)
